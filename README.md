Проанализировав вводные данные, были созданы основные модели.

1. Payer - модель "Организация". В ней основная информация о пользователе, который совершает платеж. 
2. Operation - модель "Операция". В ней сохраняем всю информацию о совершенном действии.
3. Payment - модель "Платеж". В ней уже сохраняем действие платежа с допонительной информацией, в отличии от модели Операция.
 
Операции могут быть разные, поэтому выносим это в отдельную модель.

Для работы с моделями сделаны два url

1. api/organizations/<inn>/balance   - запрос баланса (GET)
2. api/webhook/bank/ - процесс "получения" платежа (POST)
